# Training boundaries, reduced schemas and calibration

Sources: experiment_plan.json, PANEL_TASK_MANIFEST.csv, MODEL_CONFIGURATIONS.csv, BASE_MODEL_CONFIGURATIONS.csv, CALIBRATION_PROCEDURE.md, ORIGINAL_FINAL_MODEL_SEED_VERIFICATION.json and journal_revision/experiments.py::contexts/fit_task. The original model registry, preprocessing/builders.py, training/tuning.py and calibration/calibrators.py define the retained implementations.

Original preprocessing fits only inside the current training/development fold: numeric median imputation with missingness indicators; numeric scaling for Logistic Regression; categorical missing token and training-local one-hot vocabulary with unknown-category handling. There is no evaluation-fitted feature selection. PIDD physiologically implausible zeros follow the retained loader/preprocessing rule. Original model optimization used 75 trials per family/partition, development inner-fold average precision, seeded TPE and median pruning. These searches were not rerun.

Each completed reduced-schema task selects only the declared panel columns before fitting preprocessing and the base model. Original train/evaluation record and group boundaries are checked against raw stable identities and frozen splits. The original panel's development-selected family and its full-schema best_params are held fixed. Each of 234 reduced tasks uses five training-only OOF base fits and one final base fit, then applies its training-selected calibrator to evaluation scores. The 52 full-schema tasks reuse existing controls exactly. There are zero new Optuna trials. Thus the comparison isolates schema fitting conditional on frozen parameters; it is not independently retuned reduced-schema optimization or a de novo budget-matched search.

For repeated cohorts the base seed is 42 + repeat×1000 + outer_fold; OOF splitting uses base+40000, calibration uses base+50000 and final base fitting uses base+20000. Inner base estimators use OOF seed+30000+inner_fold. For holdout cohorts, frozen development folds are reused; OOF seed is 42+100000+router-family-index×10000, calibration is 42+200000+router-family-index×10000, and final fit is 42+MODEL_NAMES-index×100000+30000. Exact seeds/families per task are exported; do not substitute one generic seed for every fit.

Original full-schema calibration uses base OOF training scores. Original scenario calibration fits full-schema base learners inside training folds, masks excluded fields only in their held-out development inputs, and calibrates those scenario scores. Reduced tasks instead fit genuinely reduced-schema learners. Calibration selection adds a five-fold, class-count-capped layer on the supplied OOF scores. Individual data use shuffled StratifiedKFold; grouped data use shuffled StratifiedGroupKFold with retained seeds. The base OOF scores are reused in that layer; base models are not refitted for every calibration-validation fold.

Candidates are identity, sigmoid and isotonic. Identity clips to [1e-6, 1−1e-6]. Sigmoid fits unpenalized logistic regression (C=infinity, lbfgs, max_iter=2000) on clipped logits. Isotonic uses out_of_bounds=clip and requires at least 1,000 observations in the supplied overall calibration population. That threshold is not independently imposed on every calibration subfold; isotonic is ineligible throughout PIDD/Sylhet. Selection minimizes cross-fitted Brier score, then log loss, then configured method order. The winner is refitted on all supplied training OOF scores/labels and applied once to evaluation scores.

No evaluation outcomes enter calibration/family/hyperparameter selection. However, OOF generation conditions on parameters already selected on the same training/development partition; this is not a fully nested estimate of tuning or calibration-selection uncertainty. Development panel family selection minimizes Brier, then log loss, then negative AP. Robust family selection averages development scores across panels. Fixed families can differ across outer partitions. Evaluation calibration intercept/slope are descriptive diagnostics, never mappings fitted back onto evaluated probabilities.
