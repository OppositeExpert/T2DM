# Computational-cost methodology

Use A4_PUBLICATION_READY_SUMMARY.md beside this folder as the detailed publication-ready cost methods/results source. A4_BENCHMARK_COMPLETENESS_AUDIT.md predates supplementary timing; 06_COMPUTATIONAL_COST.csv retains all observations and result keys. A4_* summary CSVs and ANALYSIS_SOURCE_MAP.csv map every number to recorded timers, measurements or artifact bytes.

Historical tune/final-fit CSV timers are directly recorded; reliable UTC start/end metadata supports runner-invocation intervals only. Trial timestamps support within-search durations, not cross-file timezone assumptions. No missing historical OOF/preprocessing/calibration/inference duration is inferred from total runtime or unrelated runs. Historical source/hardware/installed software evidence is incomplete, so new timings are never represented as recovered historical costs. Successor OOF (including its preprocessing/fits/prediction loop), final preprocessing, final base fit and calibration-selection timers are distinct; their sums cover different completed tasks and some overlapped other work. No new tuning was performed.

Completed inference benchmarks use loaded original fitted CPU artifacts, perf_counter_ns elapsed wall time, three untimed warmups and 20 serial repetitions per workload. Report medians, linearly interpolated p05/p95 and observed ranges; do not select best-case minima. One-record calls and whole 256-record batches are separate workloads. Earlier PIDD/Sylhet batches of 154/104 records remain labeled separately. The supplement filled only missing calibration-application and exact 256-record small-cohort workloads. Finalization performs no new timing. Components include preprocessing, model prediction, calibration application, routing-only selection and end-to-end probability prediction where available. First-selected-panel component timings are not an additive decomposition of a mixed-panel batch; state that scope explicitly.

Loading, serialization, SHAP, explanation generation, input/range checking in the full patient wrapper, and report rendering are outside these probability-only timers. Cold-start time was not measured. No model training/tests ran concurrently with the controlled inference supplement; OS background activity was uncontrolled. OMP_NUM_THREADS, OPENBLAS_NUM_THREADS and VECLIB_MAXIMUM_THREADS were 1; MKL_NUM_THREADS was unset. Saved estimators retain their own n_jobs/thread_count settings, typically 4. This is not an all-single-thread estimator benchmark.

The recorded local environment is Apple M2 Pro, Mac14,9, 10 logical cores (6 performance/4 efficiency), 16 GB installed RAM, macOS 27 arm64, CPU only; Python 3.12.0; scikit-learn 1.9.0, XGBoost 3.4.1, LightGBM 4.7.0, CatBoost 1.2.10, Optuna 4.9.0, NumPy 2.5.2, pandas 3.0.5, SciPy 1.18.0, joblib 1.5.3 and threadpoolctl 3.6.0. BENCHMARK_ENVIRONMENT.json and A4_BENCHMARK_ENVIRONMENT.json distinguish prior local and supplement captures. Installed RAM is not available RAM or peak process usage. Historical hardware/runtime is unknown; the matching declared dependency-lock hash does not prove installed historical versions.

Storage is MiB = bytes/1,048,576, not decimal MB. Original file stat/hash is separate from compressed joblib=3 component serialization. Preprocessor, model, calibrator and jointly serialized prediction triple have separate sizes; compressed sizes are non-additive. A single exemplar differs from all distinct fold-family payloads needed by D's runtime router and from the independently fitted reduced-panel collection. Shared models are counted once per fitted fold-family. Canonical exemplar and selected-runtime payload sizes use saved hash-verified files. Four legacy whole-router and four component byte counts did not reproduce in a fresh process; causes remain unestablished and are disclosed rather than overwritten. Serialized bytes are not resident RAM.

Reporting completeness is COMPLETE; historical component reconstruction is PARTIAL; exact historical replay is BLOCKED. See A4_COMPARATOR_COSTS.csv for matched-workload A versus D latencies, without treating latency as evidence of superior predictive or clinical utility.
