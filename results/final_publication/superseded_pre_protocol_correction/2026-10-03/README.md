# Superseded publication summaries

Preserved on 3 October 2026 for authorized Findings A–D. These derived summaries did not implement the aggregation or resampling rules specified in the frozen protocol, or the exporter selected a different estimand. This does not imply a failed model fit. Original fitted models, predictions, calibration and threshold artifacts remain unchanged.

The 87 original registered files are preserved at their previous relative paths. `original_publication_checksums.json` reconstructs the original checksum index from these verified preserved bytes; the checksum-index file itself was not in its own registration list. `original_study_derivatives/` also preserves the original PIDD/Sylhet panel summaries, intervals, gains and fold-level comparisons. `supersession_manifest.json` identifies changed publication files and replacements. Historical forced-panel fold comparisons are preserved for provenance and excluded from current inferential claims.
